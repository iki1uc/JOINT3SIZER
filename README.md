# JOINT3SIZER · Das 3‑Achsen‑Gelenk des IKI1UC‑Systems

Der **JOINT3SIZER** ist kein normales Gelenk.  
Er ist ein **Achs‑Aktuator**, ein **Orbit‑Operator**, ein **Modus‑Regler** und das **Verbindungsstück** zwischen drei Welten:

- Pipeline 3 – Engine  
- Pipeline 6 – UI  
- Pipeline 9 – Orbit  

Er verbindet.  
Er jointet.  
Er verjoint.  
Er skaliert.  
Er trägt.  
Er ist das Gelenk, das das System zusammenhält.

### Warum „JOINT3SIZER“?

- **Joint** – Verbindung, Gelenk, Kopplung  
- **3** – drei Achsen, drei Pipelines, drei Modi  
- **Sizer** – Regler, Operator, Skalierer  

Ein Wort, das man **fühlen** kann.  
Ein Wort, das **mehr bedeutet**, als es sagt.

### Architektur

- Axiom‑Orbit‑Kernel (A.O.K)  
- NC‑Engine  
- Orbit‑Visualisierung  
- UI‑Slide‑Interface
