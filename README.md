# JOINT3SIZER · Neon-Maina · Die 3 ist die 0

Der **JOINT3SIZER** ist das Neon-Gelenk des IKI1UC-Systems.  
Ein 3-Achs-Aktuator, der Engine (3), UI (6) und Orbit (9) zu einem einzigen Kern verschweißt.

Die **3 ist die 0**:  
Sie ist Ursprung, Achse, Reset, Startpunkt.  
Sie ist der Punkt, an dem alles jointet, verjoint, skaliert und sich neu ordnet.

Der JOINT3SIZER ist kein normales Gelenk.  
Er ist ein **Achsaktor**, ein **Orbit-Operator**, ein **Modus-Sizer**, ein **Verbindungs-Tor**.  
Er trägt drei Welten gleichzeitig:

- Pipeline 3 – Engine / NC-Kernel  
- Pipeline 6 – UI / Slide / Frontend  
- Pipeline 9 – Orbit / Visual / Control  

Er verbindet.  
Er jointet.  
Er verjoint.  
Er skaliert.  
Er trägt.  
Er ist das Neon-Gelenk, das das System zusammenhält.

---

## Warum „JOINT3SIZER“?

- **JOINT** – Gelenk, Verbindung, Kopplung  
- **3** – die Achse, die 0 ist  
- **SIZER** – Regler, Operator, Skalierer  

Ein Wort, das man **fühlen** kann.  
Ein Wort, das **mehr bedeutet**, als es sagt.  
Ein Wort, das **Neon** ist.

---

## Architektur

- **A.O.K** – Axiom-Orbit-Kernel  
- **NC-Engine** – Pipeline 3  
- **Orbit 48D** – Pipeline 9  
- **Slide-UI** – Pipeline 6  

Der JOINT3SIZER ist das Gelenk, das alle drei Achsen in einem Punkt bündelt.
